# CorMista 3D — E-commerce Web App

Loja virtual moderna e minimalista para produtos exclusivos em impressão 3D e design contemporâneo.

## 🚀 Tecnologias

- **HTML5** semântico e estruturado
- **CSS3 Vanilla** com design system responsivo, microinterações e efeitos visuais
- **JavaScript Vanilla** (carrinho dinâmico, filtros de categorias, sticky header, galeria de produtos)

## 📁 Estrutura do Projeto

- `index.html` - Página principal da loja com vitrine, banner natalino e categorias
- `product.html` - Página de detalhes do produto com galeria de fotos e seletor de quantidade
- `style.css` - Estilos globais e responsividade completa (Mobile, Tablet, Desktop)
- `app.js` - Lógica da home, filtros, gaveta do carrinho e drawer
- `product.js` - Lógica da página de produto
- Assets de imagens (logo, banner, categorias e produtos)

## 📦 Como Visualizar

Basta abrir o arquivo `index.html` em qualquer navegador web ou servir via servidor local (ex: Live Server).
